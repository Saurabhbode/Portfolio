## Project Overview

**RevGen-i** is an integrated healthcare Revenue Cycle Management (RCM) and Practice Management platform designed to connect administrative, financial, clinical, and interoperability workflows within a unified system.

The platform brings together critical healthcare workflows across:

**Practice Management · Patient Eligibility · EHR Integration · Clearinghouse Connectivity · Claims · Payments · Revenue Cycle Management · HL7 Interoperability**

As a **Full-Stack Developer**, I contributed across the React frontend and Spring Boot backend, developing application features, REST APIs, data models, business validations, integrations, and healthcare workflow functionality.

My responsibilities spanned multiple layers of the application, from building user-facing interfaces and integrating APIs to implementing backend services, persistence logic, and healthcare-specific workflow processing.

# Backend Development

The backend is developed using **Java 17 and Spring Boot** with a layered application architecture:

**Controller → Service → Repository → MySQL**

My backend contribution included developing and enhancing functionality across:

### Controllers

REST endpoints responsible for handling application requests and communication between frontend interfaces and backend services.

### Services

Business logic supporting healthcare workflows, validation, processing, and integrations.

### Repositories

Persistence and database access using **Spring Data JPA and Hibernate**.

### DTOs

Structured request and response models that separate API contracts from persistence entities.

This layered structure helps maintain clear separation between API communication, business logic, and persistence.
